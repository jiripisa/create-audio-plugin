create-audio-plugin

an audio plugin for an electric guitar

A Claude Code skill that turns that one sentence into a synthesized instrument for the Mac: an Audio Unit and a standalone app, signed, notarized and on its own download page. You approve how it sounds; the rest is built for you.

Source on GitHub For Claude Code on macOS 27. Plug-ins are built for macOS 27.

From one sentence to a release

  1. Intake you

    Run it in an empty folder named after the instrument. The folder's name becomes the product's name, bundle id and Audio Unit code; you confirm it, and choose whether you want three looks to pick from or leave the look to Claude.

  2. Research

    Five researchers work in parallel on the instrument: how it makes its sound, how it is played, its relatives and variants, recordings to measure against, and how others have synthesized it.

  3. A sound to approve you

    A small prototype plays phrases of the instrument the way the plug-in will play them, and every render is measured before you hear it. Nothing is built until you say it sounds right; until then you say what to change.

  4. The build

    A spec, then the engine, the instrument's own knobs, the panel, the artwork (drawn with Codex), the bilingual website and manual, and the tests, phase by phase, each one reviewed and verified before it is merged.

  5. One question before anything goes public you

    A signed and notarized disk image, Sparkle updates and the website are ready locally. One question names every push; only your yes creates the GitHub repo, the release, the website and the catalog entry.

What every instrument gets

Its own sound and knobs

The synthesis and the list of knobs are designed for each instrument from the research and the approved prototype; nothing is sampled. A flute and an electric guitar end up with different controls.

A playing platform

Poly, Mono and Legato voices, glide, pitch bend, the sustain pedal, mod wheel and aftertouch. Two LFOs and the velocity move any knob by an amount set on the knob, on the keyboard and on the sixteen pads alike.

App and Audio Unit

A Mac app with an on-screen keyboard and pads, and an Audio Unit instrument with the same window for Logic Pro, Ableton Live and other hosts. Presets, kits and MIDI learn, shared by both.

Built to last

Parameter IDs that never change, so later versions can add knobs without breaking anyone's saved projects. Hundreds of platform tests, a test of the engine against the approved prototype, and Apple's auval check in every phase.

Use it

Install it as a personal skill, then open Claude Code in an empty folder and ask:

git clone https://github.com/jiripisa/create-audio-plugin.git
ln -s "$PWD/create-audio-plugin" ~/.claude/skills/create-audio-plugin

mkdir ~/Music/Strunka && cd ~/Music/Strunka
claude
› an audio plugin for an electric guitar

Run it in auto mode: a run takes hours and should not wait on permission prompts.

What it needs

  • Claude Code, and full Xcode for the app icon (no Xcode project is used)
  • A new-macos-app skill with the --templates renderer; the change is in patches/
  • A Developer ID certificate and a notary notarytool profile
  • A Sparkle signing key in the login Keychain
  • The gh CLI, logged in
  • Codex for the artwork; without it the look is plain SwiftUI

It is written for my own set-up: my GitHub account, my signing identity and my Audio Unit manufacturer code. Take it as a worked method, or change those to yours.
