create-audio-plugin

chci audio plugin pro elektrickou kytaru

Skill pro Claude Code, který z této jedné věty udělá syntetizovaný nástroj pro Mac: Audio Unit a samostatnou aplikaci, podepsanou, notarizovanou a s vlastní stránkou ke stažení. Vy schválíte, jak zní; zbytek se postaví za vás.

Zdrojový kód na GitHubu Pro Claude Code na macOS 27. Pluginy jsou pro macOS 27.

Od jedné věty k vydání

  1. Zadání vy

    Spustíte ho v prázdné složce pojmenované po nástroji. Jméno složky se stane jménem produktu, jeho bundle id a kódem Audio Unitu; vy ho potvrdíte a vyberete, jestli chcete tři vzhledy na výběr, nebo vzhled necháte na Claudovi.

  2. Průzkum

    Pět výzkumníků souběžně zkoumá nástroj: jak vzniká jeho zvuk, jak se na něj hraje, jeho příbuzné a varianty, nahrávky k proměření a jak ho syntetizovali jiní.

  3. Zvuk ke schválení vy

    Malý prototyp zahraje fráze nástroje tak, jak je bude hrát plugin, a každá nahrávka se před poslechem změří. Dokud neřeknete, že zní správně, nic se nestaví; do té doby říkáte, co změnit.

  4. Stavba

    Specifikace, pak engine, vlastní knoby nástroje, panel, grafika (kreslí ji Codex), dvojjazyčný web a manuál a testy, fázi po fázi, každá zkontrolovaná a ověřená, než se sloučí.

  5. Jedna otázka, než se cokoli zveřejní vy

    Podepsaný a notarizovaný disk image, aktualizace přes Sparkle a web jsou připravené lokálně. Jedna otázka vyjmenuje každý push; až vaše ano založí repozitář na GitHubu, release, web a záznam v katalogu.

Co dostane každý nástroj

Vlastní zvuk a knoby

Syntéza i seznam knobů se navrhují pro každý nástroj zvlášť, podle průzkumu a schváleného prototypu; nic není samplované. Flétna a elektrická kytara skončí s jinými ovládacími prvky.

Platforma pro hraní

Hlasy Poly, Mono a Legato, glide, ohyb výšky, sustain pedál, modulační kolečko a aftertouch. Dvě LFO a velocity pohnou kterýmkoli knobem o míru nastavenou přímo na knobu, na klávesnici i na šestnácti padech.

Aplikace i Audio Unit

Aplikace pro Mac s klávesnicí a pady na obrazovce a nástroj Audio Unit se stejným oknem pro Logic Pro, Ableton Live a další hostitele. Presety, kity a MIDI learn, společné pro obojí.

Postavené, aby vydrželo

ID parametrů, která se nikdy nemění, takže další verze mohou přidat knoby, aniž by rozbily komukoli uložené projekty. Stovky testů platformy, test enginu proti schválenému prototypu a Applova kontrola auval v každé fázi.

Použití

Nainstalujte ho jako osobní skill, pak otevřete Claude Code v prázdné složce a napište:

git clone https://github.com/jiripisa/create-audio-plugin.git
ln -s "$PWD/create-audio-plugin" ~/.claude/skills/create-audio-plugin

mkdir ~/Music/Strunka && cd ~/Music/Strunka
claude
› chci audio plugin pro elektrickou kytaru

Spouštějte ho v auto mode: běh trvá hodiny a neměl by čekat na povolení.

Co potřebuje

  • Claude Code a plný Xcode kvůli ikoně aplikace (Xcode projekt se nepoužívá)
  • Skill new-macos-app s rendererem --templates; změna je v patches/
  • Certifikát Developer ID a profil notarytoolu notary
  • Podpisový klíč Sparkle v login Keychainu
  • Přihlášené CLI gh
  • Codex na grafiku; bez něj je vzhled čisté SwiftUI

Je napsaný pro moje vlastní prostředí: můj účet na GitHubu, moji podpisovou identitu a můj kód výrobce Audio Unitů. Berte ho jako vyzkoušený postup, nebo si tyhle věci změňte na svoje.
